## Delivered

Formal fidelity classes **A–E** are now part of the public LangGraph fidelity contract:

| Class | Shape | Deterministic fixture (corpus) | Live matrix (no provider) |
|-------|-------|--------------------------------|---------------------------|
| **A** Simple chain | one chain · one LLM · optional parser | `fixtures/langgraph/plain-root.jsonl` | `langgraph-no-provider-app` / matrix simple invoke |
| **B** Tool-calling agent | agent/sequence · LLM · tool · optional retry | `dynamic-tool-name.jsonl`, `pilot-shaped-bridged-tool.jsonl` | tools path in no-provider app |
| **C** Structured-output chain | sequence · LLM · parser · multi-root scaffolds OK | `moderate-structured-output.jsonl` | — (fixture-led until pilot) |
| **D** Nested subgraph | graph · subgraph · nested sequence · LLM/tool | `semantic-parent-langgraph.jsonl`, `parallel-children.jsonl` | subgraph + parallel matrix tests |
| **E** Swarm / multi-agent | supervisor/swarm · sub-agents · handoff · nested tools | `deep-swarm-nested-ok.jsonl` (positive); `deep-swarm-self-parent.jsonl` (negative/regression) | packed deep-swarm E2E |

Cross-cutting fixtures (not a fidelity class alone):

- `error-run.jsonl` — terminal error / incomplete policy
- `semantic-parent-start.jsonl` — correlation precedence

## Support-claim rule

Any public “supports LangGraph / deep swarm” claim **must** name which classes A–E are verified. Class E claims require nested LLM+tool visibility without self-parent and without hiding nodes (see [SWARM-RELATIONSHIP-INVARIANTS](../../proposals/SWARM-RELATIONSHIP-INVARIANTS.md)).

## Parent invariants (preview for 6.15-1)

Every official adapter output for a verified class should satisfy:

```text
parentId !== eventId
no parent cycle (or cycle broken with visibility-first trees)
parent references valid event or is explicitly unresolved/external
all nodes remain visible
terminal operations have terminal status
tool identity is human-meaningful
```

Conformance fixtures for self-parent, two-node cycle, unresolved external parent, multiple roots, synthetic group, nested subgraph, and concurrent branches land in **6.15-1 / 6.15-2**.

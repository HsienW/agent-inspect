## Product decisions

| Topic | Decision |
|-------|----------|
| Self-hash | `evidence.json` is never listed in its own `files[]` |
| Transition | Legacy `metadata.json` file list includes `evidence.json` |
| Hash algo | SHA-256 hex of exact UTF-8 / bytes written |
| Assessment | Manifest `assessment.status` remains **artifact** status |

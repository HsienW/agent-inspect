Mid-checkpoint review template (blank; not complete): [../reviews/V6.12-ADOPTION-4-MID-CHECKPOINT.md](../reviews/V6.12-ADOPTION-4-MID-CHECKPOINT.md).

## Allowed work during checkpoint

- Security fixes
- Correctness / compatibility / packaging fixes
- Upstream adapter repairs
- Performance regressions
- Documentation and public-truth corrections

## Prohibited

- Horizontal product expansion
- New public packages
- v7 implementation
- Fabricating adoption rows

# V6.12 — Adoption checkpoint

**Status:** Armed after **6.12.0** publication
**Duration:** eight weeks (calendar starts at publish date)
**Authority:** Stability and Focus roadmap

## Purpose

Measure retained real-world use before any v7 decision. Prefer evidence over roadmap completion.

## Allowed work during checkpoint

- Security fixes
- Correctness / compatibility / packaging fixes
- Upstream adapter repairs
- Performance regressions
- Documentation and public-truth corrections

## Prohibited

- Horizontal product expansion
- New public packages
- v7 implementation
- Fabricating adoption rows

## Evidence to collect (real only)

- Retained LangGraph/NestJS use
- Portable evidence attached to real PR/incident
- MCP coding-agent use
- Retained CI contract/gate
- Design-partner feedback

Record in [../PRE-V7-ADOPTION-EVIDENCE.md](../PRE-V7-ADOPTION-EVIDENCE.md) (or successor). Empty rows mean “not yet evidenced,” not failure of the product.

## Exit

Maintainer reviews [V7.0.0-READINESS-ASSESSMENT.md](./V7.0.0-READINESS-ASSESSMENT.md). v7 remains **conditional** and **not scheduled** until explicitly authorized.

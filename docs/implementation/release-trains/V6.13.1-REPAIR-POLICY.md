# V6.13.1 — Reserved corrective patch policy

**Status:** Conditional only — do **not** create an empty patch release.

## Allowed triggers (confirmed only)

- Packaging / type / export defect
- OS / Node regression
- Test-runner integration issue (Vitest/Jest matchers)
- Logical-projection regression
- Evidence compatibility issue
- External pilot blocker attributable to 6.13.0

## Process

1. Document the confirmed defect and reproduction.
2. Open/refresh a short `V6.13.1-EXECUTION-PLAN.md` with minimal chunks.
3. Patch Changeset → Version Packages via `publish.yml`.
4. If no trigger fires, skip 6.13.1 and proceed to 6.14.0 planning.

# V6.15.1 — Consumer and documentation corrective patch policy

**Status:** Conditional only — do **not** create an empty patch release.  
**Authority:** [../AGENTINSPECT-CANONICAL-ROADMAP-V6.14.1-TO-PRE-V7.md](../AGENTINSPECT-CANONICAL-ROADMAP-V6.14.1-TO-PRE-V7.md) §10

## Allowed triggers (confirmed only)

- Package export / TypeScript declaration defects
- CommonJS / NodeNext incompatibility
- Reader convenience API defects (`openTrace*`, TraceFacts/contract helpers)
- Docs-command mismatch
- LangChain upstream-version compatibility
- Pilot-discovered corrective fixes attributable to 6.15.0

## Process

1. Document confirmed defect and reproduction.
2. Open/refresh a short `V6.15.1-EXECUTION-PLAN.md` with minimal chunks.
3. Patch Changeset → Version Packages via `publish.yml`.
4. If no trigger fires, record a dated skip decision and begin [V6.16.0-EXECUTION-PLAN.md](./V6.16.0-EXECUTION-PLAN.md).

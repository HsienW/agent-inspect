## Acceptance checks (must be deterministic locally)

| Step | Command / surface | Pass criteria |
|------|-------------------|---------------|
| Capture/fixture | `fixtures/langgraph/moderate-structured-output.jsonl`, `deep-swarm-nested-ok.jsonl` | Valid JSONL envelopes |
| View/explain | `agent-inspect explain` / `buildLocalExplanation` | Terminal status agrees with metadata |
| TraceFacts | `openTraceFile` → `buildTraceFacts` | Tool names present; no opaque errors |
| TraceContract | `evaluateTraceContractRead` | `requireCompleted` + required tool pass |
| Check/gate | `agent-inspect check --required-tool … --require-completed` | exit 0 |
| Evidence v2 | `agent-inspect bundle` + `bundle verify` | verify OK; share profile |
| Safety | `safety.redaction` on deep-swarm | no FP on `ls_max_tokens` / `max_tokens` |
| MCP | `get_trace_facts` / summarizeSemanticParity | same finished tools as TraceFacts |
| Diff | broken vs fixed fixtures when present | structural diff without inventing edges |

# V6.14.x — Stability and adoption policy

**After:** successful **6.14.0** publication (or blocked-on-external-evidence hold)

## Allowed

- Security / correctness / compatibility / packaging / documentation fixes
- Support-level and public-truth corrections
- Updates to [V7.0.0-READINESS-ASSESSMENT.md](./V7.0.0-READINESS-ASSESSMENT.md) (assessment only)

## Prohibited

- Horizontal product expansion
- New public packages
- v7 implementation
- Fabricating adoption rows

## Duration

Eight-week maintenance / adoption period after 6.14.0 publish (calendar set at handoff). Prefer evidence over roadmap completion.

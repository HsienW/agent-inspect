# V6.9.x — Safety repair policy

**Applies after:** `6.9.0` publication or during 6.9 when precision regressions appear.

## Allowed patches

- False-positive / false-negative detector fixes with corpus tests
- Bundle gating bugs on redacted artifacts
- Parity bugs across CLI / MCP / Studio / reporters
- Docs clarifying local policy (no compliance claims)

## Prohibited

- Weakening default redaction or share checks without explicit override UX
- Hidden network / upload
- New packages
- Schema breaks

## Process

Failing corpus case → one patch commit → chunk gate → Changeset **patch** when releasing.

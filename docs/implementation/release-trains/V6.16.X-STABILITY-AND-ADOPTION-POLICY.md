# V6.16.x — Eight-week stability and adoption policy

**Authority:** [../AGENTINSPECT-CANONICAL-ROADMAP-V6.14.1-TO-PRE-V7.md](../AGENTINSPECT-CANONICAL-ROADMAP-V6.14.1-TO-PRE-V7.md) §12–13  
**Checkpoint:** [V6.16-ADOPTION-CHECKPOINT.md](./V6.16-ADOPTION-CHECKPOINT.md)

## Mode after `6.16.0` publish

Stop feature development for eight weeks. Collect real adoption evidence only.

## Allowed

- Security / correctness / compatibility fixes
- LangChain/LangGraph upstream compatibility
- Package/export fixes
- Documentation, performance, accessibility
- Confirmed pilot blockers

## Blocked

- New package / official adapter / dashboard / hosted service
- Replay, LLM judge, context optimization, browser-agent package
- New trace schema / major package restructuring
- Fabricated pilots or retention rows

## Adoption evidence (required before v7 scheduling)

See roadmap §13 and the ledger [../PRE-V7-ADOPTION-EVIDENCE.md](../PRE-V7-ADOPTION-EVIDENCE.md). Empty/`_pending_` rows mean not yet evidenced.

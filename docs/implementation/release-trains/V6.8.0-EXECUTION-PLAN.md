## Goal

Ship an explicit adapter-fidelity contract: per-invocation lifecycle, callback-reuse isolation, conservative parent reconciliation, tool identity normalization, persist-by-intent, idempotent `flush`/`finalize`/`close`, and verified LangGraph coverage.

## Current assessment

Full contract (reuse, deferred completion, semantic parents, streaming/subgraph matrix, NestJS multi-agent recipes) remains **CONFIRMED** depth work for 6.8.

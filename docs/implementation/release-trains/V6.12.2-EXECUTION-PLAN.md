## Goal

Add an internal logical lifecycle projection and route built-in checks / TraceContract / gate / safety / Evidence / MCP through shared facts so completed LangGraph-shaped traces no longer fail N-1/N-3/N-2.

## Why it matters

Without a shared semantic layer, the flagship loop `capture → check → gate → share-checked evidence` is unreliable on real NestJS/LangGraph pilots.

## Current-source assessment

Confirmed: v0.1 bridge splits start/complete; `TraceCheckFacts.events` is raw; tool matching uses finished TOOL only; token safety misses `metadata.tokens.*`.

## Out of scope

# Evidence-first CI + MCP walkthrough (6.16.0)

Local-only flagship loop. No provider keys. No AgentInspect network.

## CLI / Evidence

```bash
pnpm build
node scripts/evidence-ci-golden-paths.mjs
# or recipe:
cd examples/recipes/langgraph-gate-evidence && pnpm start
```

## Programmatic

```bash
node examples/programmatic-trace-analysis/quickstart.mjs
```

## MCP (read-only)

Configure `@agent-inspect/mcp-server` against a local `.agent-inspect` directory (see `docs/MCP.md` / coding-agent starter). Use `get_trace_facts` / check tools on the same run id used by CLI. Finished tool names must match `buildTraceFacts` / `summarizeSemanticParity`.

## CI retention

Copy `examples/recipes/langgraph-gate-evidence/workflow-example.yml` into a consumer repo. Artifacts stay on the consumer’s GitHub Actions — AgentInspect does not upload.
